Защищённая передача сообщений

Учебная система к лабораторным работам по информационной безопасности. Шифрование выполняют собственные реализации отечественных стандартов, вызываемые из веб-приложения как отдельный процесс.

Криптография

  • Кузнечик — ГОСТ Р 34.12-2015, блок 128 бит, ключ 256 бит, режим гаммирования со счётчиком (CTR)
  • Стрибог — ГОСТ Р 34.11-2012, 256 и 512 бит: хеш паролей и хеш под подпись
  • RSA — собственная длинная арифметика, модуль {% if rsa_bits %}{{ rsa_bits }}{% else %}—{% endif %} бит

Доступ

  • Гость — только открытые страницы и проверка подписи
  • Пользователь — шифрование, своя история, PDF с подписью
  • Администратор — переключение методов, все сообщения, создание учётных записей

Вход требует трёх факторов: пароль, код из письма и код приложения-аутентификатора.
